# Aptos with WalletConnect (Legacy)

The [API page](wallet-connect-api.md) documents a WalletConnect v1 custom-method integration. Keep it only as a reference for existing applications; its URI and `sendCustomRequest` calls are not a current WalletConnect integration recipe.

For a browser integration, start with [Aptos Wallet Adapter](../../support-wallet-kit/aptos-wallet-adapter.md) and verify compatibility with your installed wallet and adapter versions.
