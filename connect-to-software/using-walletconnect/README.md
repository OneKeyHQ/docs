# WalletConnect

Use a WalletConnect-capable wallet UI library when your dApp needs to connect to a separate wallet application. Configure the chains, methods, and events your application requires and handle a rejected or expired session.

* [Ethereum and EVM](eth.md)
* [Legacy Aptos integration](aptos/)

For a wallet chooser, see [Wallet UI libraries](../support-wallet-kit/). Do not reuse a WalletConnect v1 URI with a current SDK.
