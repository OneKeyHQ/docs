# Build with OneKey

Connect your dApp to the OneKey wallet, integrate directly with a hardware device, or exchange signing requests over QR.

The [OneKey developer portal](https://developer.onekey.so/en/) is the main entry point for current integration guides and SDK reference. This GitBook collection retains the existing guides and API links.

## Choose an integration

| Your application needs to…                             | Start here                                                  |
| ------------------------------------------------------ | ----------------------------------------------------------- |
| Request accounts and signatures from the OneKey wallet | [Connect a dApp](guide/web-app-integration-developer.md)    |
| Communicate directly with a OneKey hardware wallet     | [Connect hardware](guide/hardware-integration-developer.md) |
| Exchange signing data through QR codes                 | [Air-Gap SDK](connect-to-hardware/air-gap-sdk/)             |
| Contribute a feature or chain integration              | [Contributing](guide/external-contribution-guide.md)        |

## Start with one request

Choose your runtime and chain, follow the relevant setup guide, and retrieve an address before integrating transaction signing. Handle user rejection, cancellation, and disconnects alongside the successful path.

## Need help?

For integration problems, include the method name, package version, runtime, and a minimal reproduction when [reporting an issue](trouble-shooting.md#report-an-issue). Remove credentials and sensitive wallet data from examples and logs.

For help using a OneKey product, visit the [Help Center](https://help.onekey.so/) or [contact support](https://help.onekey.so/hc/requests/new).
